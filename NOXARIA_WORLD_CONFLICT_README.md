# Noxaria: World Conflict

Protótipo Android original de simulação geopolítica fictícia.

- 195 países reais + Noxária
- Noxária começa como o menor território
- simulação automática de expansão
- pausa, velocidades x1/x3/x10
- botão para fortalecer Noxária
- toque nos territórios para ver informações

Não usa artes, código ou nome do Ages of Conflict.
